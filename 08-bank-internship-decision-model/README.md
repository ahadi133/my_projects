# Bank Internship Choice Model

**Portfolio title:** Choosing a Bank Internship | Multi-Criteria Decision Model

**Portfolio description:** A Decision Oven model comparing bank internship options against criteria including reputation, learning opportunity, location convenience, work environment, career growth, and stipend.

## Project contents

- `Bank_Internship_Choice.dof` — Decision Oven model file.

## Tools and methods

Decision Oven, multi-criteria decision analysis, criteria weighting, and alternative comparison.

## Publishing notes

The `.dof` file is a native project export. Include a screenshot or plain-language summary of the criteria, weights, and result to make the analysis accessible. Treat the result as an illustrative model rather than a universal recommendation.
