# Financial Market Performance Dashboard

**Portfolio title:** Financial Market Performance | Power BI Dashboard

**Portfolio description:** A company- and year-focused dashboard for reviewing financial statement metrics. It brings together profitability cards and KPIs, cash-flow trends, employee distribution, shareholder equity comparisons, and market capitalization versus revenue.

## Project contents

- `Financial_Market_Performance.pbix` — Power BI report file with its report model.

## Tools and methods

Power BI, financial KPI design, slicers, cash-flow trend analysis, company comparisons, and combo-chart reporting.

## Publishing notes

Open the PBIX in Power BI Desktop to inspect the report. Add screenshots or a public view link if available. Confirm data provenance and permission to publish before sharing financial data.
