# Portfolio Projects

Organized source files and notes for analytics, dashboard, spreadsheet modeling, and decision-analysis projects. Each project folder includes the available native artifact and a short overview with its tools, scope, and known dependencies.

## Projects

| Project | Focus |

| [Excel Sales Dashboard](excel-sales-dashboard/README.md) | Product, market, and monthly sales performance |
| [Excel Business Models](excel-business-modeling/README.md) | Break-even, product-mix optimization, and scenarios |

## Before sharing

Check each project README for missing source data and software requirements. Verify redistribution rights for datasets and course materials before publishing. Native files such as `.pbix`, `.twb`, `.xlsx`, `.ana`, and `.dof` require their respective desktop applications to inspect or run.

## Repository notes

The original project artifacts are organized in their project folders. `.gitignore` excludes common editor, cache, and temporary files while keeping the deliverables trackable.
