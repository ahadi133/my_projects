# World GDP Dashboard

**Portfolio title:** World GDP Dashboard | Exploring Global Development Indicators

**Portfolio description:** A dashboard preview for comparing countries and regions through GDP, population, trade, land, education, health, and labor indicators. The report combines KPI cards, time-series views, a sector contribution chart, and country-level comparisons.

## Project contents

- `World_GDP_Dashboard.pdf` — static dashboard preview.

## Tools and methods

Google Data Studio (now Looker Studio), KPI design, filters, time-series analysis, sector composition, and cross-country comparison.

## Publishing notes

The editable dashboard and underlying dataset are not included. The PDF is static, so its filters cannot be used. Add a public dashboard link and cite the source dataset before presenting this as a reproducible project.
